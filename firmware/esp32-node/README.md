# ESP32 Smart Node Firmware

This module contains the embedded firmware responsible for smart device communication, occupancy sensing, appliance automation, and Matter-based interoperability.

## Responsibilities

- Occupancy detection
- Sensor data processing
- Appliance control
- Matter communication
- WiFi connectivity
- Real-time telemetry transmission

## Hardware Components

- ESP32
- PIR Sensor
- Relay Module
- Smart Plug
- Energy Meter

## Features

- Real-time occupancy monitoring
- Smart appliance automation
- Matter protocol integration
- MQTT communication
- Low-power IoT operation
